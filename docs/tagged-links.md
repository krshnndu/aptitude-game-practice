# Tagged links

Share these instead of the bare URL. Each tag shows up in `#/admin` under Traffic sources.
Format: `?utm_source=<where>&utm_medium=<type>&utm_campaign=<push>`. Keep lowercase.

Base: https://krshnndu.github.io/aptitude-game-practice/

- LinkedIn post: `?utm_source=linkedin&utm_medium=social&utm_campaign=launch`
- WhatsApp batch group: `?utm_source=whatsapp&utm_medium=dm&utm_campaign=batchmates`
- Discord/Telegram: `?utm_source=discord&utm_medium=dm&utm_campaign=friends`
- Resume or portfolio: `?utm_source=resume&utm_medium=referral&utm_campaign=profile`
- Email signature: `?utm_source=email&utm_medium=email&utm_campaign=signature`

Only the first page view of a visit carries the tag. Always share the tagged link, never the bare one.
