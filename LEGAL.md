## Privacy

The site has no accounts, cookies, analytics, trackers or third party requests. Progress and the play history behind the coach and the analytics page are stored only in the visitor's own browser (localStorage keys `cogprep.progress.v1` and `cogprep.attempts.v1`). Progress can be cleared from the Block Slide page, the history from the analytics page (after an optional JSON export), and both through browser settings. Exception: each finished timed run uploads game, set, score, solved count, duration and a random browser ID (and an optional nickname) to the leaderboard service. IP addresses are not stored and move logs are not uploaded.
